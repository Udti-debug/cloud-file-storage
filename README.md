**Cloud File Storage System**
~ Project Overview

The Cloud File Storage System is a web-based application that allows users to securely upload, manage, and organize files in a cloud-like environment. The project demonstrates core concepts of cloud storage such as authentication, file upload, file management, versioning, and sharing.

This project is developed as part of an internship / academic mini-project to understand cloud computing and web application development.

~ Objectives

To design a simple cloud-based file storage system

To implement secure user authentication

To allow users to upload and manage files

To understand basic cloud storage concepts

~ Technologies Used

HTML – Structure of the web application

CSS – Styling and layout

JavaScript – Application logic and functionality

~ Features

User login using Google OAuth (conceptual implementation)

File upload functionality

File listing and management

File versioning (basic simulation)

File sharing concept

Simple and user-friendly UI

~ How to Run the Project

Download or clone the repository

Open the project folder

Open index.html in any web browser

Use the interface to explore file upload and management features
